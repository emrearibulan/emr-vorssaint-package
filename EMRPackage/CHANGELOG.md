# emr package changelog

## 0.3.0 — 29 October 2026

- Extended App shortcuts with **Add Website…** for HTTP/HTTPS destinations and optional names.
- Open website side icons in the default browser, with the same placement, ordering and removal controls as apps.
- Fetch website icons directly from the site and its declared icon hosts; cache colour icons locally, with refresh, contrast backing and globe fallback.
- Keep icon discovery separate from saved page paths/queries, browser cookies, credentials and third-party favicon services. Bound redirects, response sizes and raster decoding.
- Preserve existing app bookmarks, saved IDs and side layouts. Added legacy/mixed-entry, URL validation, icon-discovery and local-network fixture checks.
- Updated README and feature documentation for installation and use.

## 0.2.5 — 28 October 2026

- Replaced the stacked-letter mark with the supplied lowercase emr logo across an outlined triangle.
- Bundled the original transparent PNG unchanged and rendered its silhouette with adaptive UI contrast.
- Removed outer source padding in the UI and sized the mark for feature headings and island tiles.
- Updated the README preview and asset-maintenance instructions. Feature names, saved preferences and stable IDs remain unchanged.

## 0.2.4 — 28 October 2026

- Replaced the text suffix with a minimal monochrome emr mark before top-level feature titles.
- Arranged lowercase e above m r to form a triangle, with no enclosing border.
- Restored plain Sys Performance and App shortcuts names for search and accessibility.
- Reused the mark in section menus, settings headings and the app-shortcut chooser group; individual apps and child controls stay unbranded.
- Updated the README, catalogue and maintenance convention for future additions. Saved settings and stable IDs are unchanged.

## 0.2.3 — 28 October 2026

- Tagged top-level emr additions as **Sys Performance -emr** and **App shortcuts -emr**.
- Kept individual apps/games, child controls and dialog titles untagged.
- Recorded this scope for future additions in the maintenance guide and catalogue/README checks.
- Preserved stable feature IDs and all saved preferences.

## 0.2.2 — 28 October 2026

- Corrected the feature name to **App shortcuts** in the app, package catalogue and README.
- Preserved shortcut selections, side-button positions, stable IDs and dashboard preferences.

## 0.2.1 — 28 October 2026

- Named the second bundled feature **app shortcuts** in settings, the layout editor, package catalogue and README.
- Preserved its stable feature/action IDs, selected apps, side positions and dashboard colour preferences.
- Updated the feature documentation and source installation tag to match the release.

## 0.2.0 — 28 October 2026

- Added **Apps & Games** as the second package feature: individual side icons for chosen Mac apps and CrossOver games.
- Discover CrossOver app wrappers with bottle names, select other apps, and remove or reorder saved entries in settings.
- Preserve existing layouts and preferences; place each chosen app in a free layout slot without replacing existing buttons. No app selections are bundled or launched automatically.
- Added launcher persistence/validation checks and updated installation/use documentation.

## 0.1.3 — 28 October 2026

- Published the package with **Sys Performance** as its first bundled feature.
- Expanded the README with requirements, installation, setup, capacity colours, Codex usage definitions, updates, troubleshooting, removal and development.
- Confirmed GitHub source-only distribution; no Apple Developer release/signing work is planned.
- Required an updated README and changelog with every published package update, with version/tag and feature-documentation checks in CI.
- Hardware dashboard behaviour and saved preferences are unchanged.

## 0.1.2 — 28 October 2026

- Renamed the dashboard feature to **Sys Performance** in the app, settings, tooltips and documentation.
- Preserved feature identity, app identity and saved colour choices.

## 0.1.1 — 28 October 2026

- Standardised package branding to lowercase **emr**.

## 0.1.0 — 28 October 2026

- Established the versioned companion package and source installer/updater.
- Added hardware usage colours, the saved colour picker for readings without capacity and the ChatGPT · Codex usage tile.
- Added upstream stable-release review and package verification workflows.
