# emr package changelog

## 0.2.1 — 28 October 2026

- Named the second bundled feature **app shortcuts** in settings, the layout editor, package catalogue and README.
- Preserved its stable feature/action IDs, selected apps, side positions and dashboard colour preferences.
- Updated the feature documentation and source installation tag to match the release.

## 0.2.0 — 28 October 2026

- Added **Apps & Games** as the second package feature: individual side icons for chosen Mac apps and CrossOver games.
- Discover CrossOver app wrappers with bottle names, select other apps, and remove or reorder saved entries in settings.
- Preserve existing layouts and preferences; place each chosen app in a free layout slot without replacing existing buttons. No app selections are bundled or launched automatically.
- Added launcher persistence/validation checks and updated installation/use documentation.

## 0.1.3 — 28 October 2026

- Published the package with **Sys Performance** as its first bundled feature.
- Expanded the README with requirements, installation, setup, capacity colours, Codex usage definitions, updates, troubleshooting, removal and development.
- Confirmed GitHub source-only distribution; no Apple Developer release/signing work is planned.
- Required an updated README and changelog with every published package update, with version/tag and feature-documentation checks in CI.
- Hardware dashboard behaviour and saved preferences are unchanged.

## 0.1.2 — 28 October 2026

- Renamed the dashboard feature to **Sys Performance** in the app, settings, tooltips and documentation.
- Preserved feature identity, app identity and saved colour choices.

## 0.1.1 — 28 October 2026

- Standardised package branding to lowercase **emr**.

## 0.1.0 — 28 October 2026

- Established the versioned companion package and source installer/updater.
- Added hardware usage colours, the saved colour picker for readings without capacity and the ChatGPT · Codex usage tile.
- Added upstream stable-release review and package verification workflows.
